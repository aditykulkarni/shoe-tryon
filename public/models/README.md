# Shoe model

Drop your exported shoe here as `shoe.glb`. Until then the app shows a placeholder.

The try-on code expects:

- Units in metres, +Y up, toe pointing toward +Z.
- Origin at the bottom of the heel.
- A right shoe (the app mirrors it for the left foot).
- Under about 80k triangles and 5 MB (Draco or meshopt compression is fine).

See the export path in the architecture doc for getting there from 3DEXPERIENCE.
